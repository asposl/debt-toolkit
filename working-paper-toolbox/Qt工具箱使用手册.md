# 债承底稿处理工具箱（Qt 版）使用手册

> 系统要求：Windows 10/11。个别功能（长替换、导出 PDF）**需要本机装有 Microsoft Word**。
> !!!
> 危险功能一定要提前备份文件，有可能出现文件损坏等不可逆问题
> 处理完成后一定要自己一一点阅，有时可能出现签章页插错等问题
> !!!

## 一、怎么打开

双击 `底稿工具箱Qt.exe` 即可。

|---|---|

| ② 左侧子功能 | 每个大功能下还有细分页面，点一行切换 |

## 三、第一次上手：先记住这 6 条通用规则

### 1. 所有路径都点「浏览…」按钮选

路径输入框右边都有 `浏览…` 按钮，点它选文件夹/文件最省事，也最不容易填错。
也可以直接把资源管理器地址栏里的路径粘进去。

### 2. 填过的内容会自动记住

每次点执行、以及关闭窗口时，界面上填的所有路径和选项都会自动保存。
下次打开还在，不用重复填。
（保存在程序所在目录的 `.zcode\gui_settings.json`，删掉它就恢复出厂默认，不影响功能。）

### 3. 同一时间只能跑一个任务

任务运行期间，**所有执行按钮都会变灰**，状态栏显示 `运行中:xxx`。
这是正常的，等它跑完（按钮恢复、状态栏回到「就绪」）再点下一个。

> 如果等了很久没动静：多半是 Word COM 类任务在后台调用 Word。
> 看看任务栏有没有 Word 图标，有的话**不要手动关掉它**，等它自己跑完。
> 第一次用 Word 相关功能时，可能弹出 Office 激活/配置向导，处理一下即可。

### 4. 出错了看日志区

任务失败时，日志最后会出现 `--- 结束:xxx（退出码 n，详见上方日志与 logs\ 目录）---`。
往上翻几行就能看到具体原因，常见的就是「路径不存在」「文件被占用」。

### 5. 日志区的四个小工具（右下角深色条）

| 按钮 / 勾选框 | 作用 |
|---|---|
| `运行前自动清屏` | 勾选后，每次新任务先清空日志，只留本次输出（推荐勾选） |
| `清屏` | 手动清空日志（快捷键 `Ctrl+L`），不影响正在跑的任务 |
| `保存日志` | 把日志另存成 `.log` 文件，方便发给别人排查问题 |
| `打开日志目录` | 直接打开各模块写入的日志文件目录 |

### 6. 状态栏的「脱敏模式」

右下角勾选后，所有子任务都以脱敏模式运行（`IBDW_DEMO_MODE=1`）：
初始化底稿时发行人/项目组/落款日期用示例值，产物里不写真实主体，
打印文件提取会剥掉文件名尾部的项目标识。**对外演示、录屏、截图一律勾上**。
日志本身默认就脱敏（不含本机路径与项目标识，文件名只有 `功能_时间戳`）。

### 7. 危险操作会先弹确认框

凡是**原地改文件、覆盖、删除**的操作，点下去都会先弹一个确认框，
看清提示再点「是」。确认框里写了会改什么，别闭眼点。

## 五、✍ 签章页

### 5.1 标准流程（六步）

先填上面「项目设置」三项，再按顺序点下面的步骤按钮。

| 字段 | 填什么 |
|---|---|
| 项目根目录 | 本项目底稿所在的根文件夹，六步都在这下面递归找文件 |
| 项目标识 | 如「示例」「示例」，只用于日志和清单文件名区分项目 |
| 公司关键字 | 公司全名，③ 靠它判断哪些 PDF 需要拆末页 |
| 页眉只检查不修改 | 勾选后 ② 只出检查报告、不改文件（建议先勾这个试跑一次） |
| format 仅处理最近N天 | ① 只格式化最近 N 天更新过的 docx，默认 100 |
| export PDF复用天数 | 最近 N 天生成的 PDF 直接复用不重新导出；填 **0 = 全部重导** |

| 步骤 | 做什么 | 会不会改原文件 |
|---|---|---|
| ① 刷新docx格式 | 黑体标题 + 宋体正文 + Arial 西文，1.5 倍行距 | **原地修改** |
| ② 页眉修复 | 文件名编号与页眉编号比对、替换、补建 | 默认**会改**，可勾选 dry-run 先试 |
| ③ 导出PDF拆签章页 | Word 全量转 PDF，拆末页合成 `签章页.pdf` 并生成清单 | 生成新文件，**会弹确认框** |
| ④ 过滤索引清单 | 从清单里筛掉含「索引」的条目 | 只读，生成新清单 |
| ⑤ 追加签章页 | 把 `签章页.pdf` 第 i 页追加到清单第 i 个 PDF 末尾 | **修改 PDF** |
| ⑥ 替换签字页 | 用 `签字合并.pdf` 替换无索引清单里各文件的末页 | **修改 PDF**，会弹确认框 |

⚠️ **③ 千万别连着点两遍**：拆过末页的 PDF 再被复用时，末页已经不含公司名，
会把清单冲空，⑤⑥ 就对不上号了。
需要重跑时二选一：**把项目根目录下的旧 PDF 删掉**，或**把「export PDF复用天数」设成 0**。

> !!!
> 使用插入签章页和签字页功能时一定要找到对应的json文件和log文件，将文件内容与纸质版匹配后再运行
> !!!

### 5.2 清单与路径（④-⑥ 的高级用法）

只有 ④-⑥ 用到，一般**留空即可**（自动取项目根目录下的默认文件）。
列在这里是为了特殊情况下手动指定：

| 字段 | 说明 |
|---|---|
| 项目根目录（⑤追加/⑥替换） | 只对 ⑤⑥ 生效；留空则用「标准流程」页的项目根目录 |
| JSON 清单（④ 过滤输入） | ④ 的输入清单；留空取 `logs\no_company_…json` |
| JSON 清单（⑤ 追加用） | 留空取 `logs\has_company_latest.json` |
| 签章页.pdf（⑤ 追加用） | ③ 生成的签章页合集 |
| 无索引清单.log（⑥ 替换用） | 留空取 `logs\no_company_无索引_latest.log` |
| 签字合并.pdf（⑥ 替换用） | 已签字页的合并稿 |

⑤ 和 ⑥ 用的是**两组不同的文件**，别搞混：
`签章页.pdf` 由 ③ 导出生成（配 has_company 清单），
`签字合并.pdf` 是签字页合并稿（配无索引 log 清单）。

### 5.3 初始化底稿

对一整个文件夹的 docx 做批量预处理：

1. 统一字体（中文宋体 / 英文 Arial）、1.5 倍行距、页眉五号字、删除文末图片；
2. 文末**含「项目组」**的文件 → 改写成你填的项目组 + 落款日期；
3. 文末**不含**的文件 → 追加独立签章页「（本页无正文，为《标题》之签章页）」，
   同时汇总进「全部签章页.docx」。

| 字段 | 示例 |
|---|---|
| 待处理 Word 文件夹 | 要处理的 docx 根文件夹（含子文件夹） |
| 发行人 | 示例市示范区城市资产经营有限公司 |
| 项目组 | 示例项目组 |
| 落款日期 | 2026年6月　 日（日期留空待手填） |
| 汇总签章页文件名 | 全部签章页.docx |

⚠️ **原地修改、不可撤销**：点之前会弹确认框，**一定先备份一份原文件夹**。

## 六、⇄ 底稿替换

### 6.1 生成规则表（第一次用先点这里）

点「生成替换表模板」，会在指定位置生成 `替换规则表.xlsx`，内含三张表：

| 工作表 | 填什么 |
|---|---|
| 填写说明 | 先看这张 |
| 短替换 | 一行一条「查找词 → 替换词」 |
| 长替换 | 一行一条「起始关键字 / 结束关键字 / 素材文件」 |

> 同名文件已存在时不会覆盖，会提示先改名或删除。

### 6.2 执行替换

| 字段 | 说明 |
|---|---|
| 替换规则表.xlsx | 上一步生成并填好的规则表 |
| docx 根目录 | 要处理的底稿文件夹（递归子文件夹） |
| 输出目录（空=原地替换）（short） | 留空=直接改原文件；填了=另存一份 |
| 素材 docx 文件夹（long） | 规则表里素材文件的查找目录 |
| 覆盖原文件（long） | 勾选=原地覆盖；不勾=另存到下面目录 |
| 另存输出目录（long） | 不覆盖时的保存位置 |

- **短替换**：快，适合改词、改日期、删段落。
  查找词以 `regex:` 开头表示用正则；替换词留空表示删除。
- **长替换**：保格式，适合「删掉一大段再插入新素材」。
  **需要本机装 Word**，每个文件都要启动 Word 定位粘贴，速度慢属正常，建议先小批量试。

## 七、🗂 文件整理

### 7.1 比较与合并

| 按钮 | 行为 |
|---|---|
| 比较差异（SHA-256） | 递归比对 old / new 两个文件夹里的 docx，列出哪些改过、新增、缺失。**只读，不改文件** |
| 合并（new 覆盖 old，不备份！） | 按文件名匹配，用 new 覆盖 old。⚠️ **不备份**，会弹确认框 |

### 7.2 提取打印文件

把多级文件夹里的 doc/docx 平铺复制到一个文件夹，方便批量打印。

| 字段 | 说明 |
|---|---|
| 源目录 | 底稿根目录 |
| 输出目录 | 默认 `比较文件夹内容\打印文件` |
| 加序号前缀 (001_) | 按资源管理器习惯排序后加序号；重名自动改名 `xxx__2.docx` |
| 执行前清空输出目录中的 Word 文件 | 只清 Word 文件，其他类型不动 |

### 7.3 提取非Word文件

把**修改时间早于截止时间**的所有非 doc/docx 文件（pdf、xlsx、jpg…）平铺复制并编号，便于归档。

| 字段 | 说明 |
|---|---|
| 源目录 / 输出目录 | 同上 |
| 截止时间(早于此时刻) | 留空则用脚本内置常量；格式 `2026-08-01` 或 `2026-08-01 12:30` |
| 跳过的文件夹名 | 逗号分隔，支持通配符，如 `附件,历史底稿*` |
| 模拟运行 | **强烈建议先勾这个**：不复制任何文件，只把将复制的清单写进日志，确认无误后再正式跑 |

### 7.4 信息统计

填一个文件夹点「开始统计」，日志区会列出 Word 多少个、PDF 多少个、其他格式明细。
**只读，最安全**，用来快速摸清一个陌生文件夹的家底。

## 八、📄 PDF 材料（8 个子命令）

左侧点一个子功能，右侧填参数，点「执 行」。

| 子功能 | 干什么 | 关键参数 |
|---|---|---|
| **去重** | 按内容指纹对编号子文件夹去重并复制到输出目录（源目录不动） | 源目录、输出目录、复制后不先转图片比对 |
| **图片转PDF** | 递归把 jpg/jpeg/png/jfif 转成 PDF | 目标目录 |
| **台账匹配** | 两个工作表按字段匹配，加 num 列、导出未匹配 CSV | 台账 xlsx、匹配列（逗号分隔） |
| **特征合并** | 按 num 定位编号文件夹，按 合同→担保→决议→借据 优先级合并 PDF | 匹配结果 xlsx、编号文件夹根目录、输出目录 |
| **合并铺平** | 两阶段：先合并子文件夹 PDF，再铺平重编号 | 顶级文件夹、编号前缀、执行阶段 |
| **平铺重命名** | 多个子文件夹各自平铺 / 原地重命名 | 父目录、目录名清单 |
| **顺序编号** | 多个固定位置的 PDF 按给定顺序全局连贯编号 | 位置目录（每行一个）、编号前缀 |
| **重连贯编号** | 把已有「N 名称.pdf」的文件夹重排成 1/2/3… | 目标文件夹、起始编号 |

⚠️ **改名类默认只预览**：去重以外的「平铺重命名 / 顺序编号 / 重连贯编号 / 合并铺平」，
不勾「实际执行」时**只在日志里列出改名计划，不会真改**。
核对无误后勾选「实际执行」再跑一次才落盘。

⚠️ **两个会删文件的操作**：
- `图片转PDF`：转完会**删除原图片**；
- `合并铺平` 的「仅铺平」阶段：会**删除子文件夹内的原始 PDF**，不可恢复。

**填写提示**：
- 「目录名清单」是一行，多个用英文逗号分隔，可写 `2-3-5-7 固定资产科目核查:flat,2-3-5-8 无形资产科目核查`
  （`:flat` 表示平铺）；
- 「位置目录」是**每行一个**文件夹路径，顺序就是编号顺序；
- 「执行阶段」四个复选框是单选语义：都不勾 = 预览；勾「一步完成」= 直接合并 + 铺平。

## 九、📑 目录生成

1. 选好「目标文件夹」，Excel / Word 输出路径会**自动带出**（同级目录下 `【项目名】目录.xlsx`），可手动改；
2. 点「生成 Excel 目录」或「生成 Excel + Word 目录」。

生成规则：递归扫描多级结构 → 删掉无任何文件后代的空文件夹 → 同文件夹内同编号去重（取名称更长的）
→ 中文序号自然排序（第九章 < 第十章）→ 导出层级表；Word 版由 Excel 转出（文件夹名加粗）。

## 十、出问题了怎么办

| 现象 | 原因与处理 |
|---|---|
| 点按钮没反应，所有按钮灰着 | 上一个任务还在跑，看状态栏是不是 `运行中:xxx`。等它结束 |
| 弹「路径无效」 | 路径不存在或填错，点「浏览…」重新选 |
| 弹「请填写『xxx』」 | 那个必填项空着，补上 |
| 任务很快结束、退出码非 0 | 看日志最后几行，通常是路径/文件不存在；Word 类任务还可能是 Word 没装 |
| Word 相关功能卡住不动 | 后台打开了 Word，别手动关；必要时看看有没有 Office 弹窗被挡在后面 |
| 界面报「子进程启动失败」 | 打包版被误删了 `_internal` 文件夹，或被杀毒拦截。把整个文件夹加白名单 |
| 想知道程序到底动了哪些文件 | 点「打开日志目录」，里面有每个模块留下的明细日志 |
| 换了个新项目 | 只需改签章页「标准流程」页的项目根目录 / 标识 / 公司关键字，其余保持默认 |
| 设置填乱了想重来 | 关掉程序，删掉程序目录下的 `.zcode\gui_settings.json`，重启即可 |

### 日志文件都写在哪

| 场景 | 位置 |
|---|---|
| **双击 exe 运行** | exe 同级 `logs\<模块名>\`，如 `logs\比较文件夹内容\` |
| **源码运行** | 各模块目录下的 `logs\`，如 `比较文件夹内容\logs\` |
| **界面上看到的日志** | 不落盘，需要留存就点「保存日志」 |

## 十一、按场景查表（我要做 XX，点哪个？）

| 我想… | 去这里 |
|---|---|
| 先看看一个文件夹里都是啥 | 🗂 文件整理 → 信息统计 |
| 两版底稿改了哪些地方 | 🗂 文件整理 → 比较与合并 → 比较差异 |
| 把新版合并回旧版 | 🗂 文件整理 → 比较与合并 → 合并 |

## 十二、给维护者：界面与代码的对应关系

| 界面 | 代码 |
|---|---|
| 主窗口、顶栏、日志区 | `qtui/main_window.py` |
