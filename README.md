# debt-toolkit

处理债承工作的一些杂活。

本仓库收录 **债承底稿处理工具箱**：一个 Python + PySide6 桌面工具，把债券承做过程中
重复、机械的文件处理环节自动化，包括签章页拆分与追加、底稿目录生成、Word 版式刷齐、
批量替换、PDF 合并去重与编号。

> ⚠️ **先读 [`DISCLAIMER.md`](DISCLAIMER.md)。** 本仓库是**脱敏后的演示版本**，源码中的
> 主体名称、证件号、统一社会信用代码、项目代号与本机路径已替换为示例值，
> **直接运行会出现路径不存在、匹配失败、签章页识别不到等情况 —— 这是脱敏的预期后果，不是 bug。**

## 一、这个仓库是什么

- 面向**学习与流程参考**的开源版本：工具的分层、命令编排、GUI 与子进程协作方式都可以直接读。
- 不面向开箱即用：要真正跑起来，需要自己补齐项目路径、模板文件与替换规则表（见下文「脱敏提示」）。
- 不包含任何真实的客户资料、底稿、印章件或内部制度文件。

## 二、目录结构

```
debt-toolkit/
├── DISCLAIMER.md                      # 免责声明与脱敏说明（必读）
├── working-paper-toolbox/             # 底稿处理工具箱
│   ├── 底稿工具箱Qt.py                 # 主入口（PySide6，推荐）
│   ├── 底稿工具箱GUI.py                # 旧入口（Tk）

│   ├── 签章页工具/                     # 拆签字页、追加/替换签章页、页眉与格式修复
│   ├── 比较文件夹内容/                 # 目录比对合并、非 Word 文件提取
│   ├── 替换底稿内容/                   # 短替换（词对/正则）与长替换（Word COM）
│   ├── 底稿pdf材料/                    # PDF 合并/去重/编号/影像转换
│   ├── 多级文件夹生成目录/              # 目录树 → Excel → Word 目录
│   └── Qt工具箱使用手册.md
└── README.md
```

## 三、怎么跑

**环境**：Windows + Python 3.10 及以上（长替换依赖 Word COM，仅 Windows 可用）。

```bash
pip install PySide6 pandas pypdf python-docx openpyxl pypdfium2 pillow pywin32
python working-paper-toolbox/底稿工具箱Qt.py
```

没有 `requirements.txt`：依赖清单与打包命令见 `working-paper-toolbox/Qt工具箱使用手册.md`、
`README_GUI.md` 与 `底稿工具箱Qt.spec`。

## 四、脱敏提示（重要）

为了让仓库可以公开，做了以下替换，**它们会直接影响功能**：

| 被替换的内容 | 替换为 | 副作用 |
|---|---|---|
| 真实发行人/子公司名称 | `示例市…有限公司`、`示例主体001` | 公司关键字匹配失败，签章页过滤为空 |
| 项目代号（如 `26某某02`）、阶段名 | `示例项目` / `示例底稿目录` | 路径不存在，需自行改成自己的目录 |
| 本机绝对路径（含用户名） | 相对路径或系统临时目录 | 首次运行需重新指定路径 |
| 真实底稿 docx/pdf 样本 | 合成的最小 docx/pdf | 页眉、编号、索引结构不完整，格式修复/拆页可能不生效 |
| 替换规则表 `替换规则表.xlsx` | 未提供 | 需先用 `替换底稿内容/make_rules_template.py` 生成空白模板 |

另外：

- **日志默认脱敏**：日志文件名只有 `功能_时间戳`，正文里的项目根显示为 `<ROOT>`、
  用户目录显示为 `<USER>`。
- **状态栏有「脱敏模式」开关**：勾选后子进程以 `IBDW_DEMO_MODE=1` 运行，
  发行人/项目组/落款用示例值，提取打印文件时剥掉文件名尾部的项目标识。
- 若要让工具按真实数据工作，请**在你自己的私有环境里**改回真实路径与主体，
  不要把真实数据提交回本仓库。

## 五、合规提醒

工具会批量读写本机底稿文件，部分命令会在目标目录内**原地修改** Word/PDF。
使用前请备份、确认目标目录，并遵守所在机构关于底稿管理与客户信息保密的内部规定。
详见 [`DISCLAIMER.md`](DISCLAIMER.md)。
