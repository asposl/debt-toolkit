# 提取非Word文件使用说明

> 对应脚本：`比较文件夹内容\提取非Word文件.py`
>
> 功能：递归遍历多级源文件夹，把**修改时间早于截止时间**的所有**非 doc / docx 文件**（如 pdf、xlsx、jpg、txt 等）平铺复制到输出文件夹，并按原目录顺序自动编号，方便归档与批量处理。

---

## 一、快速开始

### 方式一：VSCode 直接运行（推荐）

打开 `提取非Word文件.py`，修改顶部「默认参数」区后按 F5：

```python
DEFAULT_SOURCE_FOLDER = SCRIPT_DIR                    # 多级源文件夹
DEFAULT_OUTPUT_FOLDER = SCRIPT_DIR / "非Word文件"      # 平铺输出文件夹

CUTOFF_TIME = "2026-08-24 00:00"   # 截止时间：只提取修改时间早于该时刻的文件

EXCLUDED_EXTENSIONS = {".doc", ".docx"}   # 要排除的扩展名
SKIP_FOLDER_NAMES: set[str] = set()       # 要跳过的文件夹名（支持通配符）
ADD_ORDER_PREFIX = True                   # True：加 001_ 序号前缀
CLEAR_OUTPUT = False                      # True：运行前清空输出文件夹
```

### 方式二：命令行运行

```powershell
# 最简用法（使用脚本顶部的默认常量）
python 提取非Word文件.py

# 指定源文件夹、输出文件夹和截止时间
python 提取非Word文件.py "D:\底稿" "D:\输出\非Word文件" --before "2026-08-01"

# 只按日期（当天 00:00 起）
python 提取非Word文件.py --before "2026-06-01"
```

## 二、参数说明

| 参数 | 说明 | 示例 |
| --- | --- | --- |
| `source_folder` | 多级源文件夹（可选，不传用顶部常量） | `"D:\底稿"` |
| `output_folder` | 平铺输出文件夹（可选，不存在会自动创建） | `"D:\输出"` |
| `--before` | 截止时间；不传用顶部 `CUTOFF_TIME` | `--before "2026-08-01 12:30"` |
| `--skip` | 跳过的文件夹名及其所有子文件夹；可逗号分隔或多次使用，支持通配符 | 见下文 |
| `--no-prefix` | 不添加序号前缀，重名时自动改为 `文件名__2.后缀` | — |
| `--clear-output` | 运行前先清空输出文件夹中的非 Word 文件（不会动 doc/docx 等其他内容） | — |
| `--log` | 自定义日志路径；不传时写入脚本同级 `logs\非Word_{项目名}_{时间戳}.log` | `--log D:\run.log` |

### 时间格式

`--before` 与 `CUTOFF_TIME` 支持三种写法（`/` 和 `-` 均可）：

- `2026-08-01` → 当天 00:00:00
- `2026-08-01 12:30`
- `2026-08-01 12:30:45`

判断规则：文件的**修改时间早于截止时间**即提取；等于或晚于则跳过并在报告中列出。

## 三、跳过文件夹（--skip）

命中的文件夹连同其**所有层级的子文件夹**整体跳过（遍历时直接剪枝，速度快）。

```powershell
# 跳过单个文件夹
python 提取非Word文件.py --skip 附件

# 逗号分隔多个
python 提取非Word文件.py --skip "附件,历史底稿*"

# 多次使用 --skip（效果等同逗号分隔）
python 提取非Word文件.py --skip 附件 --skip "历史底稿*" --skip 备份
```

支持通配符：`历史底稿*` 可同时匹配「历史底稿2019」「历史底稿2020」等。

命令行传入的名字会与顶部 `SKIP_FOLDER_NAMES` 常量**合并**生效。

---

## 四、编号规则

- 按资源管理器习惯排序收集：每一层先按自然顺序处理文件，再进入子文件夹；数字按数值大小排（`9-2` 在 `9-10` 前），「第X章」按中文数字参与排序。
- 默认在文件名前加序号：`001_根目录报告.pdf`、`002_说明.pdf`……序号位数随文件总数自动扩展。
- 输出文件夹中出现重名时自动追加 `__2`、`__3` 后缀，不会覆盖已有文件。

## 五、运行结果与日志

程序结束后打印（并写入日志）一份汇总报告，包含：

- **已复制**：每个文件的相对路径 → 编号后的新文件名 + 修改时间；
- **因晚于截止时间跳过**：不符合时间条件的文件及其实际修改时间；
- **跳过的文件夹**：被 `--skip` 整体排除的文件夹清单；
- **跳过的 Office 临时文件**：`~$` 开头的临时锁定文件；
- **因重名改名 / 清空的旧输出 / 清空失败 / 复制失败**。

其中「清空失败」只在极少数情况出现：输出目录里的旧文件正被其它程序占用（例如 PDF 阅读器打开着），
或当前账号没有删除权限。这类文件会跳过并列出原因，任务本身照常完成，不需要中断重跑。
复制出来的文件会自动去掉只读属性，避免下一轮清空时被系统拒绝。

日志默认保存为：`logs\非Word_{源文件夹名}_{YYYYMMDD_HHMM}.log`（UTF-8 带 BOM，可直接双击用记事本查看）。

## 六、常见问题

1. **会不会改动或移动源文件？**
   不会。全部是复制，原文件原样保留。

2. **docx / doc 文件会被复制吗？**
   不会。这两类扩展名始终被排除；如需提取 Word 文件请使用原有的「提取打印文件」功能（`folder_toolbox.py extract`）。

3. **`~$` 开头的文件去哪了？**
   属于 Office/WPS 的临时锁定文件，统一跳过并在报告中记录。

4. **重复运行会覆盖上次结果吗？**
   不加 `--clear-output` 时不会删除旧输出，但重名文件会自动加 `__2` 后缀保留两者；想得到干净的全新结果可加 `--clear-output`。

5. **怎么只跑一次某个固定项目？**
   把路径和时间写进顶部常量区即可，之后每次 F5 都是同一套配置。

6. **清空输出时报错「拒绝访问 / PermissionError」怎么办？**
   已内置处理：只读文件会先解除只读再删除；真正删不掉的（被占用/无权限）会记进报告的「清空失败」清单，
   不会让整个任务中断。看到清单时关掉占用该文件的程序（多是 PDF 阅读器），再跑一次 `--clear-output` 即可。
